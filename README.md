# Smart Date Generator

A Java console application with multiple date utilities.

## Features
- Generate random dates
- Generate DOB
- Generate future dates
- Generate multiple dates
- Show monthly calendar
- Countdown to a target date
- Weekend checker
- Lucky date detector
- Random OTP generator

## Technologies Used
- Java
- java.time package

## How To Run

Compile:
javac SmartDateGenerator.java

Run:
java SmartDateGenerator
